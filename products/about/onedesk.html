System Requirements

OneDesk is a light & versatile office solution. Almost any Windows PC which supports .NET Framework 4.8.1 can run OneDesk. Here are the officially supported Operating Systems:

  • Windows 7
  • Windows 8/8.1
  • Windows 10
  • Windows 11

    • While OneDesk may work on other systems, they are not officially supported and therefore some features may not look right or even work.
