OneDesk Version Changes (OneDesk 2025)

Version 3.1.1.25 (Released 8/27/26)

Minor Update

  • - Fixed many activation-related bugs
  • + Miscellaneous Quality of Life updates
  • + Added Digital Licenses
  • + Changed how activation status affects usage

Version 3.1.1.2 (Released 8/25/26)

Major Release

  • + Added "Wave" theme
  • + Miscellaneous Quality of Life updates
  • + Introducing Microsoftware Accounts in OneDesk! You can now sign in to your Microsoftware Account on OneDesk.
  • + Fixed sign-in activation

Version 3.1.0.21 (Released 1/18/26)

Weekly Patch/Minor Update

  • - Fixed bug in which upgrading would fail due to incorrect server URL schema.
  • + Miscellaneous Quality of Life updates
  • - Fixed uninstaller bug which caused incomplete removal of OneDesk.

Version 3.1.0.1 (Released 1/11/26)

Minor Update

  • - Fixed bug in which activation by product key fails if performed before main windows opens.
  • + Added various update system revisions.

Version 3.1.0.0 (RTM, Released 1/8/26)

Major Release

  • Original release of OneDesk 2025.
  • + Added activation by signing in with a Microsoftware Account with a digital product key linked.
